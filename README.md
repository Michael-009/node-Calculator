# Node.js Terminal Calculator

A simple command-line calculator built with Node.js. It allows users to perform basic arithmetic operations like addition, subtraction, multiplication, and division — all through terminal interaction.

---

## Features

- Terminal-based input/output
- Modular design using custom math functions
- Error handling (e.g., division by zero)
- Clean and colorful console UI with `chalk`
- Beginner-friendly code structure
